# Задание для Codex, Claude или другого исполнителя

- **ID и базовый коммит** — результат `context ID` и текущий `origin/main`.
- **Цель и границы** — один проверяемый результат, решения владельца и ограничения.
- **Входные файлы** — несколько путей из карточки. Для больших каталогов укажите точные ID сущностей.
- **Зависимости** — ID выполненных задач и обязательные разрешения.
- **Критерии готовности** — наблюдаемое поведение, совместимость сохранений и обработка отказов.
- **Проверки** — точные команды и ожидаемые признаки успеха. Отмечайте фактически выполненные отдельно.
- **Передача** — `checkpoint ID --note "изменения, файлы и проверки" --next "первое оставшееся действие"`.
- **Завершение** — `done ID --note "результат и ограничения" --commit HASH`. Карточка закрытия строится из журнала.
