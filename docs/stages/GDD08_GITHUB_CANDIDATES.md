# GDD-08 Социальные системы: кандидаты с GitHub

Статус: **утверждено 2026-11-22** по рекомендациям: внедрений нет. Дата поиска: 2026-11-22.

## Источники механик
Вики Atlantica недоступна (HTTP 402). На atlantica-online.wikidot.com найдены только каркасные страницы PvP
(Кронос, Арена, Колизей, Свободная лига) и таблица рангов Свободной лиги. Правил гильдий, групп и чата там нет.

## Главный вывод поиска
Поиск по темам «подбор соперников», «чат», «рейтинг Эло», «гильдии», «друзья», «фильтр ненормативной лексики»
вернул единичные небольшие репозитории или ничего. Этого и следовало ждать: эти системы живут на сервере и зависят
от модели игры, а не от движка. Логику пишем сами на RefCounted по правилам, зафиксированным в `data/social.json`.

## Внедрено
Ничего. Реализовано самостоятельно в `src/shared/social/`.
