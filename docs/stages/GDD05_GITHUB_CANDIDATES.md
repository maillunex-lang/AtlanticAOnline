# GDD-05 Наёмники и классы: кандидаты с GitHub

Статус: **утверждено 2026-11-22** (wyvernshield-triggers внедрён как образец без копирования кода, остальные изучены; дизайн: оружие определяет навыки, без старения, оба способа найма). См. docs/GDD05_MERCENARIES.md. Дата поиска: 2026-11-22.

## Источники механик
Вики Atlantica недоступна (HTTP 402). Использованы вторичные источники (дневник разработчиков на TenTonHammer,
Engadget, Allakhazam, 2008-2010 годы), детали могли измениться. Из них следует:
- Тип оружия бойца определяет его навыки и магию; у героя и наёмников набор типов оружия общий
  (меч, копьё, топор, ружьё, лук, пушка, посох).
- Наёмник при найме получает 1 базовую магию, дальше до 5. При повышении уровня героя наёмники получают
  очко характеристик и очко навыков.
- Есть ступени улучшения (базовый класс, затем продвинутый с лучшими статами за уровень и ресурсы).
  Продвинутые наёмники получаются через квесты найма, одного такого типа на отряд.
- Наёмники со временем стареют и слабеют, поэтому их нужно обновлять.
- Редкость как отдельная система в источниках не описана: ближайшее по смыслу это ступени.

## Главный вывод поиска
Готовые «ability system» и «stat» плагины для Godot рассчитаны на реальное время и узлы сцены
(например, LiGameAcademy/godot_ability_system: около 14 тысяч строк GDScript). Они не подходят для нашей
детерминированной симуляции `BattleSim`, которая работает на RefCounted без сцен. Зависимостей не берём:
статы, модификаторы и навыки пишем сами как данные (Resource) и чистую логику, а чужие проекты используем как образец.
