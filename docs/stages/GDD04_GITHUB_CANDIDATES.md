# GDD-04 Боевая система: кандидаты с GitHub

Статус: **ожидает утверждения**. Дата поиска: 2026-11-22.

## Ограничение по источникам механик
Прямой доступ к atlantica.fandom.com закрыт (сервер отвечает HTTP 402). Механики взяты из поиска по
вторичным источникам (Allakhazam wiki, обзоры) и **противоречат друг другу в деталях хода**. Поэтому
правила боя в GDD-04 задаём как параметры в данных, а точные числа настроим игровыми тестами.
Подтверждено несколькими источниками: сетка формации 3x3, отряд до 9 бойцов (герой и до 8 наёмников),
в раунде действуют не все (до 5), у наёмников есть «очки действий», перемещение в бою тратит очки.
Не подтверждено: точный порядок ходов сторон, формулы урона, значения очков действий по классам.

## Главный вывод поиска
Готовой библиотеки боя с формациями 3x3 и растущим числом ходящих на GitHub нет. Ядро боя пишем сами
как **чистую детерминированную симуляцию** в `src/shared/battle/` (без сцен и UI), которую запускают
и клиент (предпросмотр), и сервер (истина). Чужой код берём как образец структуры.

## Не берём
Аддоны конечных автоматов (лицензии NOASSERTION или нет лицензии, боевой цикл проще написать enum-ом), всплывающие числа урона (пишутся за час).

## Решение по модели хода
Выбирает владелец проекта (см. страницу выбора). Рекомендация: стороны ходят по очереди, число действующих
бойцов растёт с каждым ходом до лимита, перемещение тратит очки действий.
