# GDD-06 Прогрессия и предметы: кандидаты с GitHub

Статус: **утверждено 2026-11-22** по рекомендациям (Lootie как образец, остальные изучены; слоты B, улучшение B, опыт A, крафт A). См. docs/GDD06_PROGRESSION_ITEMS.md. Дата поиска: 2026-11-22.

## Источники механик
Два поиска по предметам, улучшению и крафту Atlantica не вернули ни одной страницы об этой игре (только
другие MMORPG), а вики Atlantica недоступна (HTTP 402). Поэтому система предметов, улучшения, крафта и опыта
строится **по жанровым практикам и нашим решениям из GDD-04 и GDD-05**, а не по данным оригинала.
Единственное, что известно из прошлых этапов: при получении уровня героя наёмники получают очко
характеристик и очко навыков (уже реализовано).

## Главный вывод поиска
Готовые инвентари для Godot есть и зрелые (gloot, wyvernbox, pandora), но их логика переплетена с узлами
сцены и редакторскими плагинами, а наш сервер хранит и проверяет всё как чистые данные. Для сервера
нужна небольшая логика на RefCounted: предмет, слоты экипировки, правила стеков, таблицы добычи.
Её пишем сами, а чужие проекты берём как образец и для клиентского UI инвентаря на GDD-10.
