# GDD-07 Квесты, NPC и подземелья: кандидаты с GitHub

Статус: **утверждено 2026-11-22** по рекомендациям: две идеи использованы, остальное оставлено на GDD-10. Дата поиска: 2026-11-22.

## Источники механик
Вики недоступна (HTTP 402). Вторичные источники: основная линия и побочные задания, ежедневные задания с бонусным
опытом, квесты найма наёмников с требованием уровня. Часть сведений устарела (2008-2011).

## Главный вывод поиска
Квестовых и диалоговых систем для Godot много, но они рассчитаны на локальную игру: состояние хранится в узлах,
диалоги исполняются на клиенте. Нашему серверу нужна чистая проверяемая логика: журнал, события, награды, условия.
Её пишем сами (на RefCounted, без сцен), а зрелые диалоговые проекты берём для клиентского UI.
