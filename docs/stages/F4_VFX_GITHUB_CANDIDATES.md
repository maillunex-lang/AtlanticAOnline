# Графика навыков и эффектов (WP-47G): кандидаты с GitHub

Шлюз выполнен 2026-11-22 перед временной графикой навыков. Запросы: `godot vfx`, `godot particles effects`, `pixel art effects`, `game-icons`, `pixel icons rpg`, `godot hit effect`.

| Репозиторий | Звёзды | Лицензия | Что даёт | Решение |
|-------------|--------|----------|----------|---------|
| cs5475/free-pixel-effects | 0 | CC0 1.0 | 30 разовых эффектов (12 взрывов, 10 искр удара, 8 вспышек магии), листы PNG + готовые SpriteFrames .tres для Godot 4 | **берём** (только файлы, кода нет; проверено содержимое, лицензия в LICENSE) |
| patch-gg/pixelfx | 8705 | MIT (часть кода Hugo Duprez, MIT) | 244 эффекта кодом на JS: лечение, яд, оглушение, проклятие, щит, рубящие удары; экспорт листов `node tools/sheets.mjs` | нужен запуск чужого кода и `npm ci`; **ждёт решения владельца**; при согласии берём только отрендеренные листы, уведомление MIT в `third_party/ASSETS.md` |
| game-icons/icons | 1370 | CC BY 3.0 (SVG) | ~4000 иконок | отложено: нужна ссылка на авторов, стиль векторный, не пиксельный |
| RPicster/Godot-particle-and-vfx-textures | 379 | CC0 1.0 | текстуры частиц | запасной вариант для частиц |
| gdquest-demos/godot-visual-effects | 1350 | не определена | примеры эффектов | отклонить (лицензия) |
| haowg/GODOT-VFX-LIBRARY | 359 | MIT | частицы и шейдеры | запасной вариант |
| Huu-Yuu/PixelSRPG-Forge | 481 | MIT | пиксельные ресурсы SRPG | не проверен, лицензия на ресурсы внутри неясна |

Вывод: удары, взрывы и вспышки магии берём из CC0-набора cs5475. Лечение, яд, оглушение, проклятие, щит и рубящие удары можно получить из pixelfx. Иконки навыков собираем генератором из имеющихся иконок оружия и рамок по роли.
