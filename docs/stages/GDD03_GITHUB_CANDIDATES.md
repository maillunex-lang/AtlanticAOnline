# GDD-03 Мир и карта: кандидаты с GitHub

Статус: **утверждено 2026-11-22** по рекомендациям: внедрений нет, три проекта оставлены на GDD-10/11. Дата поиска: 2026-11-22.

## Источники механик
Вики недоступна (HTTP 402). Вторичные источники описывают мир на реальной географии, города с бюро путешествий,
телепорт за восстанавливаемый ресурс, бой при контакте с врагом, подземелья по ключу. Часть источников сомнительна.

## Главный вывод поиска
Серверная логика мира (граф зон, маршруты, открытие карты, столкновения) в готовом виде на GitHub не нашлась, и это
не требуется: мир у нас граф зон, а не гекс- или тайл-сетка, кратчайший путь пишется короткой Дейкстрой, а встроенные
в Godot A* и поиск пути ничем не лучше для небольшого графа. Для клиента (UI карты, туман, тайловые карты зон) есть
годные проекты, но они нужны на этапах GDD-10 и GDD-11.

## Внедрено
Ничего. Логика написана самостоятельно (`src/shared/world/`).
