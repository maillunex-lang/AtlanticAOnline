# План создания игры (для людей и для других ИИ)

Этот пакет документов описывает, **что должно быть в игре** и **в каком порядке её делать**, чтобы продолжать работу мог любой разработчик или ИИ-агент
без доступа к истории чата. Игра: Android MMORPG на Godot 4.7 с пошаговыми боями по образцу Atlantica Online, оригинальный контент.

## С чего начать
**Сразу к работе:** откройте `ROADMAP.md` (раздел 0 «Как работать») и выполните `python3 tools/roadmap.py next`: инструмент покажет следующую задачу, что читать, приёмку и шлюз GitHub. Ниже порядок чтения для знакомства с проектом.

1. Прочитайте [AI_HANDOFF.md](AI_HANDOFF.md): состояние проекта, структура, команды, грабли, правила по правам на контент.
1a. Прочитайте [DESIGN_GUARD.md](DESIGN_GUARD.md): охранные правила замысла, которые нельзя нарушать ни одному GDD и пакету.
2. Прочитайте [GAME_SPEC.md](GAME_SPEC.md): полное описание систем игры, что уже есть и чего не хватает.
3. Берите работу из [BUILD_ORDER.md](BUILD_ORDER.md) по порядку пакетов (WP-xx). У каждого есть цель, зависимости, файлы и критерии приёмки.
4. Для мира, квестов и боя есть отдельные документы: [WORLD_DESIGN.md](WORLD_DESIGN.md), [QUEST_DESIGN.md](QUEST_DESIGN.md), [COMBAT_REVISION.md](COMBAT_REVISION.md).
5. Как добавлять контент (регион, зона, квест, наёмник): [CONTENT_PIPELINE.md](CONTENT_PIPELINE.md).
5a. Факты оригинала по системам (бой, характеристики, предметы, гильдии, дом, PvP, подземелья, наёмники): каталог [wiki/](wiki/README.md), числовые таблицы [reference/wiki_numbers.json](reference/wiki_numbers.json).
5b. Перед каждой фазой делайте поиск на GitHub по [GITHUB_RESEARCH.md](GITHUB_RESEARCH.md) (шлюз).
6. Справочные факты об оригинальной игре (числа, структура, реальная география): [reference/atlantica_reference.json](reference/atlantica_reference.json).

## Источники и права
Сведения об оригинале получены из полной выгрузки зеркала вики Atlantica (rikagro.ru, 6659 страниц, тексты CC BY-SA 3.0), вики wikidot и обзоров. Из них взяты **структура, числа и правила**
(механики не защищены), а не тексты. Названия заданий, имена NPC, тексты, рисунки и музыку оригинала **не переносим**: весь контент оригинальный.
Реальная география (континенты, города) используется свободно. Сырую выгрузку вики в репозиторий не кладём.
Подробности по источникам: [../SOURCES.md](../SOURCES.md).
