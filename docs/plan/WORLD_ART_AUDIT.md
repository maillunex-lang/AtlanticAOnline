# Аудит доступных локаций

Проверены 30 локаций с 41 загружаемым чанком. В сценах используются 89 маркеров групп противников. Количество групп показывает заполнение карты в сюжетном режиме. Общие группы с масштабированием по числу игроков проверяются в отдельном сетевом пилоте Поющих дюн.

## Что изменилось

- Луга получили две дополнительные группы, лес — две, Старая шахта — две. Число обязательных встреч в сюжете не изменилось.
- Добавлено 74 декоративных объекта из девяти оригинальных пиксельных наборов. Для воды, полотна, огня, травы и искр используются короткие циклы. Декор подгружается с чанками и не участвует в проверке столкновений.
- Проверены ссылки на ресурсы всех сцен чанков. Существующие проверки также проверяют текстуры монстров и предметов. Герои используют покадровые клипы, жители ходят по расписанию, противники на карте используют простую анимацию ожидания. У части жителей и противников ещё нет отдельных покадровых циклов ходьбы и боя.
