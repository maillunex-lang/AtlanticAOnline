# Порядок работ

Текущий порядок, зависимости и статусы берите из [реестра задач](tasks.json).
Для чтения используйте [дорожную карту](../../ROADMAP.md) или `python3 tools/roadmap.py next`. Для одной задачи запустите `python3 tools/roadmap.py context ID`.

[Исторический план пакетов](BUILD_ORDER_ARCHIVE.md) сохранён для поиска первоначальных критериев и решений.
