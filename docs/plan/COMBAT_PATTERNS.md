# Шаблоны поражения по типам оружия (спецификация для WP-11A)

Одно правило для симуляции, ИИ и подсветки в интерфейсе: функция `BattleSim.hit_set(actor_id, target_id) -> Array[int]` возвращает id всех поражаемых бойцов, а `legal_targets` строится на её основе.
Клиент подсвечивает ровно то, что вернула эта функция, ИИ оценивает выбор по ней же. Тест обязан сверять, что три потребителя получают один результат.

## Координаты
Слот стороны = `ряд * 3 + колонка`, ряд 0..2 сверху вниз, **колонка 0 ближайшая к врагу** (передняя линия), колонка 2 дальняя.
Терминология вики и наша различается, поэтому ниже используем **только наши термины**:
- **линия** = колонка (общая глубина): вики называет её «front row» (передний ряд);
- **луч** = ряд (идёт вглубь, от колонки 0 к колонке 2): вики называет его «column».

Схема вражеской формации (номера слотов):
```
        к игроку  <- колонка 0 | колонка 1 | колонка 2
ряд 0:              0       1       2
ряд 1:              3       4       5
ряд 2:              6       7       8
```
Пустой слот называется «пробел».

## Передняя линия цели
Ближние виды оружия выбирают цель только в **передней занятой колонке** (самая малая колонка, где есть живой боец). Когда она вымерла, передней становится следующая.
Дальние и магия выбирают цель по правилам своего оружия (таблица).

## Таблица шаблонов
«Выбранный» боец это тот, по кому игрок или ИИ нанёс удар (центр шаблона). Результат это множество поражаемых живых бойцов; пустые слоты и мёртвые пропускаются.

| Оружие (id) | Вид | Кого можно выбрать | Что поражается |
|-------------|-----|--------------------|----------------|
| sword | ближний | любой в передней колонке | только выбранный |
| dual_sword | ближний, бьёт летающих | любой в передней колонке | выбранный, соседи сверху и снизу в той же колонке, боец сразу за ним в том же ряду (колонка+1): максимум 4 |
| spear | ближний | любой в передней колонке | выбранный и боец сразу за ним в том же ряду (колонка+1), если слот занят |
| armor_fist | ближний | любой в передней колонке | то же, что spear |
| axe | ближний | любой в передней колонке | вся передняя колонка подряд от выбранного вверх и вниз без пробелов (максимум 3) |
| power_saw | ближний | любой в передней колонке | то же, что axe |
| bow | дальний, бьёт летающих | любой живой | только выбранный |
| gun | дальний, бьёт летающих | любой живой | весь луч выбранного (колонки 0..2 того же ряда), в том числе через пробелы: максимум 3 |
| instrument | дальний, бьёт летающих | любой живой | выбранный и боец сразу за ним (колонка+1) в том же ряду; пробел обрывает |
| cannon | дальний, **не бьёт летающих** | любой живой наземный | выбранный как центр креста плюс 4 соседа (слева, справа, сверху, снизу по сетке 3x3), существующие и наземные: максимум 5 |
| whip | дальний, бьёт летающих | любой живой | выбранный и соседние бойцы подряд по его колонке вверх и вниз без пробелов (максимум 3) |
| staff | магия, бьёт летающих | любой в передней колонке | только выбранный (навыки посоха используют собственную дальность навыка, WP-47) |

«Бьёт летающих» перечислено в 03_CONTENT_FACTS.md: лук, ружьё, инструмент, кнут, парные мечи, посох и магия. Ближние (меч, копьё, кулак, топор, пила) и пушка **не поражают** летающих: летающий боец не попадает ни в выбор, ни в итоговое множество.

## Правило летающих
1. Боец с флагом `flying` (поле данных монстра) не может быть выбран и не попадает в множество у оружия без права бить летающих.
2. Если боец передней колонки в ряду летающий, ближний боец может выбрать **ближайшего наземного бойца за ним в том же ряду** (он проходит под летающим). Правило и источник зафиксированы в [журнале решений](../DECISIONS.md).
3. Магические навыки действуют по полю дальности навыка и могут бить летающих.

## Примеры (обязательные тесты WP-11A, формация врагов полностью занята, слоты 0..8)
| Оружие | Выбранный | Ожидаемое множество слотов |
|--------|-----------|----------------------------|
| sword | 3 | {3} |
| dual_sword | 3 | {3, 0, 6, 4} |
| dual_sword | 0 | {0, 3, 1} (сверху нет, соседей снизу и за спиной по одному) |
| spear | 3 | {3, 4} |
| spear | 5 | недопустимая цель: слот 5 не в передней колонке, ошибка `unreachable` |
| axe | 3 | {0, 3, 6} |
| bow | 8 | {8} |
| gun | 4 | {3, 4, 5} |
| gun | 3 при пробеле в слоте 4 | {3, 5} (пробел пропускается) |
| instrument | 4 | {4, 5} |
| instrument | 4 при пробеле в слоте 5 | {4} |
| cannon | 4 | {4, 1, 7, 3, 5} |
| cannon | 0 | {0, 1, 3} (края сетки отсекаются) |
| whip | 4 | {1, 4, 7} |
| whip | 4 при пробеле в слоте 7 | {1, 4} |
| axe, передняя колонка не полная: заняты 0 и 6, пробел в 3 | выбран 0 | {0} (пробел в слоте 3 обрывает линию) |

Обязательные граничные случаи: пробел внутри луча (gun против instrument), край сетки (cannon в углу), первая колонка вымерла и вторая стала передней, летающий в передней колонке (меч выбирает наземного за ним), пушка и меч против летающего (нет цели), обычная атака посохом против магического навыка с собственной дальностью.

## Урон обычной атаки

Базовая сила увеличивается на 12% за свободный слот в своей формации, до трёх слотов.
За один удар очки действия списываются один раз, а защита, разброс и крит считаются отдельно для каждого попадания.
Параметры бонуса заданы в `BattleRules`.

## Граница с WP-41
WP-11A реализует и тестирует **все 12** шаблонов на тестовых данных. В игровом каталоге (`data/weapons.json`) остаются 7 типов (меч, копьё, топор, ружьё, лук, пушка, посох): демо использует их и показывает зону поражения подсветкой. Новые пять типов (кнут, парные мечи, кулак, пила, инструмент) в каталог и к наёмникам добавляет WP-41.
