# GDD-10. UI/UX (горизонтальный режим)

Статус: **утверждено 2026-11-22** (по рекомендациям), реализовано в демо-клиенте и проверено на виртуальном дисплее.
Вид игры сохранён по утверждённой демо-версии (docs/GDD.md, раздел 2.1).

## 1. Принципы
- Только горизонтальная ориентация (1280x720 как базовая сетка, растяжение `canvas_items`, `expand`).
- Управление касанием: кнопки не ниже 64 px, шрифт не меньше 16 (основной 20-26), цели касания не мельче 92 px у слотов.
- Пиксельный стиль: панели и кнопки 9-slice из плиток Kenney UI Pack (CC0) в масштабе x4, пиксельная графика без сглаживания.
- Один путь к любой функции: кнопка «Меню» на карте открывает окно с вкладками. Закрыть можно в один тап.
- Весь интерфейс, бой и мир собраны как **сцены Godot** (`scenes/ui`, `scenes/battle`, `scenes/world`) с общей темой `theme/pixel_theme.tres`, их можно править
  в редакторе на компьютере (docs/EDITING.md). Экраны растягиваются под любой формат за счёт якорей (проверено на 16:9 и 2.2:1).
- Состояние хранит клиентский `DemoMain`, экраны только показывают и вызывают общую логику (`Squad`, `Inventory`, `Enhancer`,
  `Crafter`, `QuestLog`). Те же вызовы будут идти через сервер.

## 2. Экраны
| Экран | Что есть |
|-------|----------|
| Карта (HUD) | Герой, уровень, опыт, монеты, зона, трекер заданий, миникарта, кнопка «Меню» (с точкой, если задание можно сдать), подсказки, экранный джойстик по желанию |
| Меню: Отряд | Список бойцов, их статы, опыт, навыки, очки, четыре слота снаряжения с выбором предмета, формация 3x3 |
| Меню: Сумка | Сетка предметов и материалов (лимит 60), подробности предмета, «Надеть на» любого бойца (с причиной отказа), переход в кузницу |
| Меню: Кузница | Улучшение: шанс, серия неудач, цена, результат. Крафт: список рецептов, нехватка монет и материалов |
| Меню: Задания | Активные задания с прогрессом, наградой и NPC для сдачи, «Бросить», счётчик ежедневных |
| Меню: Настройки | Скорость боя x1-x3, касание или джойстик, подсказки, автобой с начала боя. Сохраняются в `user://demo_settings.cfg` |
| Бой | Формации 3x3. Внизу плитки бойцов (портрет, здоровье, ОД, отметка «ходил»), по касанию плитки или бойца на поле открывается меню действий: атака, умения героя с иконкой, описанием и ценой (защита, лечение, усиления), сместиться, ждать. Затем цель. Закончить ход, автобой, бегство, скорость из настроек |
| Диалог, результат боя | Панели в том же стиле |

## 3. Формация
Расстановка хранится как `uid бойца -> слот`. Выбор клетки меняет бойцов местами, если она занята. Расстановка применяется
в следующем бою. Правила передней линии из GDD-04 объясняются в подсказке.

## 4. Безопасная область и устройства
`UiKit.safe_margins` вычисляет поля по вырезам экрана (`DisplayServer.get_display_safe_area`) для будущего применения к HUD.
В демо HUD пока не сдвигается: на устройстве с вырезом нужно проверить.

## 5. Не входит в этап
| Что | Когда |
|-----|-------|
| Адаптация под разные соотношения сторон и маленькие экраны (до 5 дюймов), масштаб интерфейса | после проверки на устройствах |
| Окна друзей, чата, гильдии, группы, PvP | вместе с сетевым слоем |
| Магазин, торговля, аукцион | GDD-09 (экономика) |
| Локализация (интерфейс только на русском) | GDD-12 |
| Доступность: размер шрифта, режим для дальтоников, вибрация | GDD-12 |
| Собственные иконки навыков и предметов (часть иконок временная) | GDD-11 |

## 6. Заимствования
Графика интерфейса: Kenney UI Pack Pixel Adventure (CC0). Код интерфейса свой. Кандидаты и причины отказов:
docs/stages/GDD10_GITHUB_CANDIDATES.md.
