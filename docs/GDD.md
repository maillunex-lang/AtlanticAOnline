# GDD — Atlantic Online (рабочее название)

Версия: 1.1 · Дата: 2026-11-22 · Статус: GDD-02..08 и 10 реализованы как логика и демо; бой переведён на модель очков действий (WP-10). Дальнейшая работа ведётся по пакетам docs/plan/BUILD_ORDER.md

## 1. Видение
Android-MMORPG с пошаговой тактикой в стиле Atlantica Online: мир в реальном времени
(перемещение, города, квесты, NPC) + пошаговые бои на сетке с формациями наёмников.

- Платформа: Android (минимум API 26, ARM64), только **горизонтальная** ориентация.
- Движок: Godot 4.7 (GDScript основной язык; C#/GDExtension — по необходимости).
- Модель: клиент-серверная, авторитетный сервер (клиент — только отображение и ввод).
- Аудитория: игроки, любящие пошаговые тактики, гринд, гильдии и PvP/войны.

## 2. Принципы и решения (утверждены 2026-11-22, см. DECISIONS.md)
1. **Адаптация механик, не копирование контента.** Механики (формации, наёмники, пошаговый бой,
   гильдии, осады) не защищены авторским правом. Названия, лор, тексты, арты, музыка, модели
   и карты из оригинала **не переносим** — всё оригинальное или с свободной лицензией.
   Wiki используется как справочник по механикам и балансу.
2. Сервер: Godot headless с общим кодом боя; бой при росте онлайна выносится в отдельный сервис.
3. Карта мира: вдохновлена реальной географией (континенты → регионы → города/подземелья),
   как в оригинале, но с собственными названиями и разметкой.
4. «Полная адаптация» делается итерациями (см. ROADMAP.md); сначала вертикальный срез.
5. Мобильный UX: управление одним пальцем/касанием, авто-бой, короткие сессии.

## 2.1 Визуальный стиль (утверждён 2026-11-22)

**Stylized Fantasy MMORPG.** Художественно стилизованная графика с живописными материалами, мягким светом и читаемыми силуэтами. Мир показан сверху, боевые отряды стоят в двух формациях 3×3. Игровая сетка мира составляет 64 px. Детализация и фильтрация подбираются для каждого слоя под мобильный экран.

Интерфейс использует тёмно-синие панели с золотыми рамками, выразительные иконки и крупные сенсорные кнопки. Русский текст выводит движок. В текущей сборке окружение и часть интерфейса уже обновлены. Для завершения перехода нужны стилизованные персонажи, монстры, здания и анимации. [Визуальный стандарт](plan/art/VISUAL_SYSTEM.md)

## 3. Этапы GDD
Полномочия исполнителя и владельца описаны в ROADMAP.md (раздел 0): мелкие и технические решения исполнитель принимает сам и записывает в DECISIONS.md; архитектурные, продуктовые, юридические и денежные только с ответом владельца.

Каждый этап: (а) ты выбираешь этап → (б) я ищу на GitHub полезные библиотеки/шаблоны/ассеты
и пишу рекомендации «что внедряем и как адаптируем» → (в) ты утверждаешь → (г) я пишу раздел GDD,
внедряю в репозиторий и обновляю ROADMAP.md.

## 4. Нефункциональные требования (предварительно)
- 60 FPS на среднем устройстве (Snapdragon 6-серии), старт < 5 с, размер APK < 150 МБ (+ подгрузка).
- Трафик: компактный бинарный протокол, переподключение без потери состояния боя.
- Безопасность: сервер авторитетен для боя, лута, экономики; валидация всех команд.
