# Правка интерфейса и локаций в редакторе Godot

Проект открывается в **Godot 4.7.2** (обычная версия, не .NET): выберите файл `project.godot` в окне «Project Manager».
Первый импорт занимает около минуты. Запуск игры: F5. Нужные сцены лежат в `scenes/`, общая тема интерфейса в `theme/`.

## 1. Где что лежит
| Что | Файлы |
|-----|-------|
| Общая тема кнопок, панелей, шрифтов | `theme/pixel_theme.tres` |
| HUD на карте | `scenes/ui/hud.tscn` |
| Меню и вкладки (Отряд, Сумка, Кузница, Задания, Настройки) | `scenes/ui/menu.tscn` и `scenes/ui/tab_*.tscn` |
| Панель диалога и итога боя | `scenes/ui/info_panel.tscn` |
| Элементы списков (строка списка, ячейка предмета, карточка задания) | `scenes/ui/list_button.tscn`, `item_cell.tscn`, `quest_card.tscn` |
| Экран боя | `scenes/battle/battle_view.tscn` |
| Боец на поле, плитка героя внизу, строка меню действий | `scenes/battle/unit_view.tscn`, `hero_chip.tscn`, `action_button.tscn` |
| Мир целиком | `scenes/world/world.tscn` |
| Локации (куски мира) | `scenes/world/loc_harbor.tscn`, `loc_meadow.tscn`, `loc_forest.tscn` |
| Враги, NPC и герой на карте | `scenes/world/enemy_spawn.tscn`, `npc_marker.tscn`, `hero.tscn` |
| Набор плиток для рисования | `tilesets/world_tiles.tres`, атлас `demo/assets/atlas/world.png` |

## 2. Интерфейс
- Все экраны растягиваются под любой формат экрана за счёт **якорей** и контейнеров (проверено на 16:9 и 2.2:1). Меняйте якоря в панели «Layout», а не
  абсолютные координаты.
- Внешний вид кнопок и панелей: откройте `theme/pixel_theme.tres` (двойной щелчок), раздел Button, PanelContainer и т.д. Размеры шрифтов и
  цвета правятся в инспекторе у выбранного узла (Theme Overrides).
- **Узлы с уникальными именами** (в дереве у них значок `%`) используются скриптами. Их можно двигать, менять размеры, стили и вид,
  но **не переименовывайте и не удаляйте**, иначе скрипт не найдёт узел. Остальные узлы можно менять свободно.
- Динамические списки (бойцы, предметы, рецепты, задания, кнопки действий) заполняются скриптом из маленьких сцен. Меняйте вид одной
  такой сцены, и он поменяется везде.
- Тексты и числа берутся из `data/*.json`, их правят там.

## 3. Локации
- Мир собран из **кусков-локаций**, лежащих вплотную друг к другу в `world.tscn` (узел `Chunks`). Между ними нет загрузок: герой просто
  переходит границу. Куски вне экрана автоматически отключаются (подгрузка по расстоянию), поэтому мир можно расширять.
- Откройте, например, `scenes/world/loc_meadow.tscn`. У куска два слоя: **Ground** (земля, дороги, вода) и **Objects** (дома, деревья, указатели).
  Выберите слой, внизу появится панель TileMap с плитками, рисуйте кистью.
- Жёлтая рамка в редакторе показывает границы куска (`size_tiles` в инспекторе у корня). Рисуйте внутри рамки.
- **Проходимость.** У плиток есть свойство `blocked` (вода, деревья, дома, указатели непроходимы). Свойство меняется в редакторе набора плиток
  (`tilesets/world_tiles.tres`, вкладка TileSet, Custom Data). Герой не заходит на плитки с blocked.
- **Враги.** Добавьте в кусок сцену `enemy_spawn.tscn` (Instance Child Scene), поставьте на карту и укажите `encounter_id` из `data/encounters.json`.
  Вид группы и подпись подхватятся сами.
- **NPC.** Добавьте `npc_marker.tscn`, укажите `npc_id` из `data/npcs.json` и `sprite_name` (имя файла из `demo/assets/chars` без `.png`).
- **Старт героя.** Узел `PlayerStart` в куске `loc_harbor`. Его можно двигать.
- **Зона.** В инспекторе корня куска заданы `zone_id`, `zone_name`, `min_level` и цвет на миникарте.

### Как добавить новую локацию
1. В `world.tscn` перетащите нужную сцену куска в узел `Chunks` (или сделайте копию `loc_meadow.tscn` через Save As и переименуйте).
2. Поставьте её **вплотную** к соседу по горизонтали (позиция по X равна правому краю соседа, по Y ноль). Правый край кратен 64 пикселям.
3. Задайте `zone_id`, `zone_name`, `size_tiles` (высота как у соседей), нарисуйте землю так, чтобы дорога и трава на границе совпадали.
4. Нужные данные зоны (уровень, враги) добавьте в `data/world.json` и `data/encounters.json`.
5. Запустите тесты (раздел 6): они проверят, что куски стыкуются без щелей и земля закрашена целиком.

## 4. Бой
`scenes/battle/battle_view.tscn`: верхняя полоса, журнал, нижняя панель (плитки бойцов, кнопки), меню действий (`ActionPopup`).
Расстояния между клетками формации и поля задаются в инспекторе корня (`front_gap`, `col_step`, `top_margin`, `bottom_margin`).
Фон боя рисует скрипт `demo/battle/battle_background.gd` (трава и полоса земли из плиток), тон правится в инспекторе.

## 5. Если что-то сломали
- Все сцены лежат в git (`main`), откатить файл можно командой `git checkout -- путь/к/файлу.tscn` или в GitHub Desktop.
- Сцены можно **пересоздать с нуля** генераторами: `tools/gen_battle.gd`, `tools/gen_ui.gd`, `tools/gen_world.gd`
  (`godot --headless --path . -s tools/gen_ui.gd`). Внимание: генератор **перезаписывает ваши правки** этих сцен.

## 6. Проверки и сборка
- Тесты: Godot, меню GdUnit4 внизу редактора, либо `godot --headless --path . -s -d res://addons/gdUnit4/bin/GdUnitCmdTool.gd --ignoreHeadlessMode -a res://tests`.
  Тесты `tests/world/test_world_scenes.gd` проверяют целостность мира, остальные игровую логику.
- Сборка APK: меню Project, Export, пресет Android (нужны шаблоны экспорта 4.7.2 и Android SDK, см. docs/DEMO.md).
