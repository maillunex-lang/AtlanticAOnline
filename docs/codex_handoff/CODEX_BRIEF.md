# ТЗ CODEX: полный перезапуск контента NPC и квестов

## Задача
Построить оригинальную связанную RPG-систему NPC, сюжетных, побочных, рекрутинговых, ежедневных и иных квестов по всем регионам ATLANTICA. Не копировать художественные тексты, диалоги, персонажей и защищённые названия Atlantica Wiki. Wiki-данные использовать как справочный материал для структуры, категорий и последовательности, с ручной проверкой спорных связей.

## Архитектурные ограничения
- Сохранить Godot 4.7.2, MMO-протокол, серверную авторитетность, QuestLog, боевую систему, сохранения, обучение и интерфейсы.
- Не удалять все quests/npcs/chains/dialogues одновременно. Мигрировать по одному региону с возможностью отката.
- Старые ID из сохранений сохранять или мигрировать через явную таблицу legacy_id -> new_id. Без проверки миграции не удалять старые записи.
- Не менять production, не трогать другие проекты VPS, не выпускать APK, не пушить без разрешения.
- Текущие локальные 4 изменённых файла квестов/тестов могут отсутствовать в GitHub: сверить перед работой.

## Приоритеты и порядок
1. Северо-Восточная Азия: 8 зон, 29 цепочек, заменить временный контент на оригинальную согласованную историю и NPC.
2. Юго-Восточная Азия и Индия: 4 зоны, 2 цепочки, заменить контент.
3. Остальные 11 регионов: создавать зоны, NPC, диалоги, цепочки, столкновения и награды одновременно.
4. Учитывать зависимости сюжета и уровневые диапазоны REGION_MANIFEST.json, не создавать недоступные цепочки.

## Для каждого региона
A. Сопоставить источники из source_reference с новыми игровыми сущностями. В каждой записи mapping указать source_id, game_id, уверенность, решение, причину и открытые вопросы. Не выдумывать отсутствующие соответствия.
B. Спроектировать географию и переходы, города, подземелья, NPC и роли, монстров и предметы.
C. Составить граф основных, побочных, найма наёмников, титулов и повторяемых цепочек по уровню и применимости. Явно указать prerequisites, reset, rewards.
D. Создать оригинальные диалоги: приветствие, locked, offer, accepted, in_progress, ready_to_turn_in, completed, fallback, несколько ответов для ключевых NPC.
E. Реализовать игровые данные по текущим JSON-схемам. Расширение схемы только отдельным этапом с тестами.
F. Прогнать валидаторы ссылок, циклов, доступности, наград, повторного входа, Godot headless import, gdUnit4 и smoke.
G. Составить миграцию legacy ID, dry-run на сохранениях и отдельный PR/коммит по региону. Удалить старый контент только после переключения и проверки.

## Обязательные проверки
- Нет битых quest->giver/turn_in, npc->zone/dialogue, chain->steps/prereq, objective->encounter/item/zone и world->edges.
- Нет циклов prereq, недостижимых обязательных заданий, пустых веток диалога.
- Все квесты выдаются/сдаются корректно, награды только сервером и строго однократно.
- Все NPC с квестовой ролью имеют диалоги; цепочки с наймом действительно выдают соответствующего наёмника.
- Нет регрессии обучения, боёв, существующих сохранений и сетевого протокола.
- Не ослаблять тесты для прохождения CI.

## Формат результата Codex
Для каждого региона: количество зон/NPC/цепочек/квестов/диалогов, source mapping, нерешённые источники, миграция, отчёт тестов, ограничения, diff/PR.
